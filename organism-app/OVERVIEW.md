## Architecture Genius

**Two-part system:**

1. **React Frontend** (The Face)
   - Clean, minimal interface
   - Real-time WebSocket updates
   - Beautiful animations (Framer Motion)
   - Settings hidden unless needed

2. **Python Backend** (The Brain)
   - Flask API + WebSocket server
   - Organism intelligence layer
   - Backend manager (LlamaFile/Claude/GPT)
   - Evolution history & rollback

**Connected via:**
- WebSocket for live updates
- HTTP API for commands
- All processing happens server-side
